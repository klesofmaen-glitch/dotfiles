# Cosmic Kitty Theme

Тема терминала Kitty в стиле Material 3 и космической эстетики, созданная для гармоничной работы с Waybar и обоями вашего рабочего стола.

## Особенности темы

### 🌌 Космическая эстетика
- Темные тона с глубоким космическим фоном
- Голубые акценты, напоминающие свечение горизонта
- Фиолетовые и розовые оттенки для создания космической атмосферы

### 🎨 Material 3 дизайн
- Цветовая схема, вдохновленная Material Design 3
- Полупрозрачность для лучшей интеграции с обоями
- Мягкие тени и плавные переходы

### 🚀 Функциональность
- Powerline-стиль для панели вкладок
- Горячие клавиши для управления прозрачностью
- Улучшенная навигация мышью и клавиатурой
- Поддержка копирования в буфер обмена

## Установка и использование

### 1. Применение темы

Тема уже настроена и активна. Просто перезапустите Kitty для применения изменений.

### 2. Переключение тем

Используйте скрипт `theme-switcher.sh` для переключения между темами:

```bash
# Показать доступные темы
~/.config/kitty/theme-switcher.sh list

# Показать текущую тему
~/.config/kitty/theme-switcher.sh current

# Переключиться на другую тему
~/.config/kitty/theme-switcher.sh <имя_темы>
```

### 3. Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl+Shift+U > 0` | Увеличить прозрачность |
| `Ctrl+Shift+U > 9` | Уменьшить прозрачность |
| `Ctrl+Shift+C` | Копировать в буфер обмена |
| `Ctrl+Shift+V` | Вставить из буфера обмена |
| `Ctrl+Shift+N` | Следующее окно |
| `Ctrl+Shift+P` | Предыдущее окно |
| `Ctrl+Shift+W` | Закрыть окно |
| `Ctrl+Shift+T` | Новая вкладка |
| `Ctrl+Shift+S` | Вертикальное расположение |
| `Ctrl+Shift+D` | Горизонтальное расположение |

### 4. Настройка прозрачности

Тема поддерживает динамическую прозрачность:
- Используйте горячие клавиши `Ctrl+Shift+U > 0` и `Ctrl+Shift+U > 9`
- Или измените значения в `kitty.conf`:
  ```conf
  background_opacity 0.95
  dynamic_background_opacity yes
  ```

## Интеграция с Waybar

Тема создана в едином стиле с вашим Waybar:
- Цветовая схема соответствует Material 3 токенам
- Полупрозрачность позволяет обоям просвечиваться
- Акцентные цвета синхронизированы с Waybar

## Настройка под ваши обои

Если вы хотите настроить тему под конкретные обои:

1. Измените основной цвет фона в `themes/cosmic.conf`:
   ```conf
   background #ВАШ_ЦВЕТ
   ```

2. Подберите акцентные цвета, которые гармонируют с обоями
3. Настройте прозрачность для оптимального вида

## Дополнительные настройки

Все основные настройки находятся в `kitty.conf`:
- Размер шрифта: `font_size 20.0`
- Отступы окна: `window_padding_width 15`
- Стиль панели вкладок: `tab_bar_style powerline`

## Советы по использованию

1. Для лучшего вида используйте шрифты с поддержкой Nerd Font
2. Экспериментируйте с прозрачностью в зависимости от обоев
3. Используйте горячие клавиши для быстрой навигации
4. При добавлении новых тем обновляйте массив в `theme-switcher.sh`

## Проблемы и вопросы

Если у вас возникнут проблемы с темой или вопросы по настройке, проверьте:
1. Правильность путей к файлам
2. Совместимость версии Kitty
3. Наличие необходимых шрифтов
